# CLI Music Player — Rules

This is a college project. Keep the code simple and short.

- Use CommonJS `require`, not `import`
- Only built-in modules: `fs`, `path`, `child_process`
- No external packages, no frameworks
- Keep functions under 20 lines
- Comment WHY a line exists, and what it does
- Prefer readable code over clever code
- Never add a feature that wasn't asked for
